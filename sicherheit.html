Sicherheit

Öffentlich heißt nicht ungeschützt

Lesen ≠ Schreiben

Jeder darf den öffentlichen Code ansehen. Das Originalrepository verändern können jedoch nur autorisierte Konten. Externe Beiträge laufen über Forks und Pull Requests.

Veröffentlichung

Nur geprüfte Änderungen auf main werden veröffentlicht. Ein Branch-Ruleset soll direkte Änderungen, Force-Pushes und Löschungen absichern.

Schülerdaten

Die Plattform ist ohne Schülerkonto geplant. Modelle sollen keine personenbezogenen Schülerdaten erfassen und keine Tracker oder Werbung enthalten.
