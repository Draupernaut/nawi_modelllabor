# Verhaltenskodex

Das NaWi-Modelllabor soll eine sachliche, respektvolle Zusammenarbeit ermöglichen. Beiträge werden nach fachlicher Qualität, didaktischer Eignung, Sicherheit und Wartbarkeit beurteilt – nicht nach Status oder technischer Erfahrung der beitragenden Person.

Kritik an Modellen und Code ist ausdrücklich erwünscht, soll aber konkret und respektvoll formuliert werden. Diskriminierende, beleidigende oder einschüchternde Beiträge werden nicht akzeptiert.
