Eigene Modelle beitragen

Andere Lehrkräfte können Modelle entwickeln, ohne Schreibrechte auf die öffentliche Website zu erhalten.

So funktioniert es

1 · ForkEine eigene Kopie des Repositories anlegen.
2 · Modell bauenDie Vorlage nutzen und lokal testen.
3 · Pull RequestDie Änderung zur Prüfung einreichen.
4 · ReviewFachlichkeit, Modellgrenzen, Bedienbarkeit und Code werden geprüft.

Qualitätsstandard

Keine Tracker oder Schülerkonten; Modellgrenzen sichtbar machen; Touch-Bedienung; verständliche Größen und Einheiten; keine ungeklärten Lehrbuchabbildungen; robuste Fehlerzustände. Details stehen im Repository in CONTRIBUTING.md.
