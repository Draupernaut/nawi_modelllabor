# Modellvorlage

1. Ordner nach `models/chemie/<slug>/` oder `models/biologie/<slug>/` kopieren.
2. Titel, Beschreibung und sichtbare Modellgrenzen ergänzen.
3. Keine Tracker, Werbung oder ungeprüften externen Skripte einbauen.
4. Touch-Bedienung, Pause und Reset testen.
5. Einen Eintrag in `catalog.json` ergänzen.
6. `npm run validate` ausführen.
