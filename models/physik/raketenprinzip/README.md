# Raketenprinzip

Unterrichtsmodell für Profil 9 und Physik 9–12. Drei Ansichten: Rückstoß / äußerer Druckluftstart, senkrechter Aufstieg, fairer Stufenvergleich. Alle Zahlen sind frei gewählte Modellwerte, keine Auslegungsdaten für reale Raketen. Keine externen Bibliotheken oder Datenerfassung.

Lokal vom Repository-Stamm: `python3 -m http.server 8000`; dann `http://localhost:8000/models/physik/raketenprinzip/` öffnen.

Physiktests: `node models/physik/raketenprinzip/test.mjs`. Repository-Validierung: `npm run validate`.

Prüfung vor Veröffentlichung: Browser- und Touch-Sichtkontrolle, Präsentationsmodus, alle Regler und Pause/Reset. Die Modellgrenzen stehen direkt in der Oberfläche. Code MIT, didaktische Inhalte und eigene Grafiken CC BY-SA 4.0.
